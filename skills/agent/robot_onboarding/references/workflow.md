# Simulation-first workflow

1. Use the inspector output; do not silently repair its warnings.
2. Ask a human to confirm each canonical joint name, policy index, sign, limit and actuator binding.
3. Create a `simulation-only` Profile draft and run L0 schema/mapping validation.
4. L1 requires a reproducible MJLab play or simulation record.
5. Physical capability needs a driver, calibration, safety profile and dedicated gates; it is not implied by L0 or L1.
